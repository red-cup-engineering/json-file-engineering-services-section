This path proves JSON serialization. JSON Lines and EAVT are deeper restrictions
owned by the same recovered codec actuator and exposed as explicit subpaths.

`json-schema-service` is the one combined specification cell for deterministic
JSON Schema creation and bounded resolution/validation judgments. It consumes
JSON values after codec admission; it is not a JSON projector or a second codec.
Its validation verdict is non-monotone, so it cannot be represented as a
decidable file read.
